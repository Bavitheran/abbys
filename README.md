# The Abbys Trading Journal

A private, single-user trading journal that runs directly in a browser. It has no server, login, cloud sync, broker connection, or external font requests.

## Open it

Open `index.html` in a current desktop or mobile browser. Your accounts and trades are saved in that browser's local storage.

Use **Settings → Download backup** to save a JSON backup, including any uploaded chart images. Use **Import backup** to restore that file in another browser. Chart screenshots are compressed before saving to keep the local journal smaller. Clearing browser data can erase the journal, so keep a backup if you want a second copy.

## Included

- Dashboard with net P&L, win rate, average R, profit factor, equity curve, account balance, daily stop, and guardrail progress
- Multiple personal, evaluation, funded, or paper accounts with editable limits and currency
- Trade log with long/short, result, fees, points, planned risk, quantity, times, setup, session, grade, chart link, compressed chart image upload, notes, and rule adherence
- Dashboard daily profit/loss bars with green profit days and red loss days, a cumulative P&L area chart, and The Abbys Score radar across six journal metrics
- The Abbys Score summarizes win rate, consistency, profit factor, average win/loss, recovery factor, and drawdown using the selected date range
- Searchable and filterable journal, monthly calendar, and setup/session review summaries
- JSON export and import

All values are for personal record keeping. The guardrails display progress but do not connect to a broker or block orders.
